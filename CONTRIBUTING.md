# Contributing

Iter is a personal project, and I'm glad you're trying it.

- **Bug reports and ideas are welcome.** Please [open an issue](https://github.com/dwjames88/iter/issues/new?template=bug.md) using the Bug report template.
- **Please don't open pull requests yet.** They won't be merged for now, and I'd hate for you to spend time on one.
- **Security problems:** please don't put details in a public issue. Use GitHub's private vulnerability reporting (the Security tab) if it is enabled. If not, open an issue that says only that you have a security concern and asks for a way to get in touch, and I'll reply.
- **Building it yourself:** see the [For developers](README.md#for-developers) section of the README.
