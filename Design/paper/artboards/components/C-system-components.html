System components
macOS 26 controls · Design/COMPONENTS.md · System components
Iter relies on these system controls and does not restyle them: it configures them. Each is drawn with the macOS 26 look, light and dark, with the notes on how Iter uses it. Coral enters only through the app accent.
Stand-ins
MapKit, Look Around, materials and the system tab bar are drawn as stand-ins (named with (swap)); the Settings tab bar follows the standard macOS Settings look, not the broken snapshot.
NavigationSplitView with a sidebar List
.listStyle(.sidebar); two sections ("Trips": All Trips + one row per trip; "Find": Explore, Saved, Scout), selection bound to the window's navigation; sidebar width 200 / 240 / 320 pt; the Sample data banner is a bottom safe-area inset; a "New Trip" toolbar button. Detail column is a NavigationStack per section.
